# Starter v0.2 — 桌面 EXE 客户端路线图

## 目标

把现有 MVP（CLI + MCP + SQLite）打包成 **Windows 桌面客户端**：
- 图形 UI（F1-F10）
- 后台服务（HKLM 写 + 真实启动调度）
- 系统托盘 + 开机自启
- .msi 安装包

## 架构

```
┌─────────────────────────────────────────────────────────┐
│  桌面 UI (Tauri + HTML/JS，约 10MB)                      │
│  - 系统托盘 + 通知                                       │
│  - 启动项列表 / 详情 / 时间线                            │
│  - 通过 HTTP 调 Daemon（127.0.0.1:7811）                 │
└──────────────────┬───────────────────────────────────────┘
                   │ HTTP + Bearer Token
                   ▼
┌─────────────────────────────────────────────────────────┐
│  Daemon (Node.js + node-windows, 装成 Windows Service)   │
│  - SYSTEM 跑（HKLM 写无需 UAC）                          │
│  - 端口 127.0.0.1:7811                                   │
│  - 持久 SQLite（%ProgramData%\Starter\starter.db）       │
│  - 登录后调度 + IO 监控 + 真起进程                       │
└─────────────────────────────────────────────────────────┘
```

## 路线图

### 阶段 A：基础（v0.2.0-alpha，2-3 轮）
1. **Batch 8**：建 `packages/daemon/` 骨架
   - node-windows 包装 + `sc create` 安装脚本
   - HTTP server（127.0.0.1:7811）+ Bearer token
   - 复用 `@starter/core` 业务逻辑（scan / enable / disable / setDelay）
   - HKLM 写支持（Daemon 跑在 SYSTEM 无需 UAC）
2. **Batch 9**：Daemon 真实启动调度
   - CreateProcess 真起进程（替换模拟）
   - SetPriorityClass
   - 在登录时（Task Scheduler Logon trigger）调度
3. **Batch 10**：Tauri 桌面 UI
   - 建 `packages/ui/` （HTML/JS 简单版）
   - Tauri 配置 + 托盘
   - 列表 / 启停 / 延迟 / 时间线

### 阶段 B：完善（v0.2.0，2-3 轮）
4. **Batch 11**：F7 时间线 UI（甘特图）
5. **Batch 12**：F10 托盘 + 开机自启
6. **Batch 13**：打包 .msi / .exe，GitHub Actions 自动发布

### 阶段 C：长期（v0.3+）
7. 升级 React Native 桌面 UI（替换简单 HTML）
8. macOS / Linux scanner
9. 云同步 / 账号
